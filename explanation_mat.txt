3) TUTTI I FLAG MP: FORMULE + RIGHE CODICE
-------------------------------------------

3.1 --min-green, --max-green
- Effetto:
  - min_green: tempo minimo prima di rivalutare switch.
  - max_green: cap di sicurezza per non tenere troppo una fase.
- Codice:
  - check min_green: max_pressure.py:543-544
  - check max_green: max_pressure.py:565-568


3.2 --switch-epsilon
- Margine base:
  switch_margin = switch_epsilon
- Codice: max_pressure.py:199


3.3 --lost-time-aware, --lost-time-sat-flow, --lost-time-gain

3.3.1 Lost time di transizione
- Formula:
  T_lost = somma durate fasi non-main dopo current_phase fino alla prossima main
- Codice: max_pressure.py:187-196

3.3.2 Margine LTA
- Formula:
  switch_margin = switch_epsilon + lost_time_gain * lost_time_sat_flow * T_lost
- Codice: max_pressure.py:198-205

3.3.3 Validazione sat_flow
- Regola:
  se lost_time_aware o nmin_dynamic allora lost_time_sat_flow > 0
- Codice: runner.py:92-93


3.4 --fairness, --fairness-mu, --fairness-w-half

3.4.1 Update wait per fase
- Regole:
  - fase corrente: w_phi = 0
  - fase non corrente con domanda > 0: w_phi += delta_t
  - fase senza domanda: w_phi = 0
- Codice: max_pressure.py:397-410

3.4.2 Bonus fairness saturato
- Formula:
  bonus_phi = mu * (w_phi / (w_phi + w_half))
- Caso limite:
  se w_half <= 0 allora bonus_phi = mu
- Codice: max_pressure.py:411-416

3.4.3 Score finale
- Formula:
  score_phi = P_phi + bonus_phi
- Codice: max_pressure.py:424-425


3.5 --downstream-penalty, --downstream-beta, --downstream-alpha

3.5.1 Occupazione EMA
- Formula:
  occ_ema(t) = alpha * occ_raw(t) + (1-alpha) * occ_ema(t-1)
- Codice: max_pressure.py:212-220

3.5.2 Penalita movimento
- Formula:
  penalty_m = downstream_beta * occ_down_ema
- Codice: max_pressure.py:245-249

3.5.3 Pressione movimento penalizzata
- Formula:
  p_m = q_in - q_out - penalty_m
- Codice: max_pressure.py:385-387


3.6 --spillback, --spillback-on, --spillback-off, --spillback-min-halts, --spillback-alpha

3.6.1 Occupazione EMA spillback
- Stessa formula EMA, ma cache dedicata spillback.
- Codice: max_pressure.py:222-224

3.6.2 Regola hard con isteresi
- Se lane non bloccata:
  blocked = (occ_ema >= spillback_on) and (halts >= spillback_min_halts)
- Se lane gia bloccata:
  blocked = (occ_ema >= spillback_off)
- Codice: max_pressure.py:236-241

3.6.3 Effetto sulla fase
- Se anche un solo movimento punta a out_lane bloccata:
  phase_blocked = True, quindi P_phi = -inf
- Codice: max_pressure.py:379-391


3.7 --platoon-extension, --platoon-headway-threshold,
    --platoon-gap-out-seconds, --platoon-max-extra-green, --platoon-guard-occ

3.7.1 Detector virtuale near stop-line
- Posizione detector:
  detector_pos = lane_length - 8.0m
- Codice: max_pressure.py:39, 251-253

3.7.2 Headway stimato
- Si registrano tempi passaggio lane.
- Headway medio recente:
  headway = mean(Delta t ultimi passaggi)
- Codice: max_pressure.py:255-300

3.7.3 Condizione platoon
- Almeno una in_lane della fase con:
  headway <= platoon_headway_threshold
- Codice: max_pressure.py:337-343

3.7.4 Guardia downstream
- Estensione consentita solo se:
  - non blocked da spillback hard (se attivo)
  - occ_down_ema < platoon_guard_occ
- Codice: max_pressure.py:302-308

3.7.5 Budget estensione
- Non estende oltre:
  active_platoon_extension_seconds < platoon_max_extra_green
  e spent < max_green
- Codice: max_pressure.py:324-327, 348-349


3.8 --nmin-dynamic, --nmin-alpha, --nmin-floor, --nmin-empty-release-seconds

3.8.1 Target servizio post-switch
- Formula:
  n_cost   = nmin_alpha * lost_time_sat_flow * T_lost
  n_target = max(nmin_floor, n_cost)
- Codice: max_pressure.py:435-438

3.8.2 Clamp alla domanda fase
- Formula:
  n_target = min(n_target, demand_current_phase) se demand > 0
- Codice: max_pressure.py:440-443

3.8.3 Hold dinamico in secondi
- Formula:
  hold_seconds = max(min_green, n_target / lost_time_sat_flow)
- Codice: max_pressure.py:444-445

3.8.4 Rilascio anticipato fase vuota
- Se fase vuota, accumula active_empty_seconds e rilascia quando:
  active_empty_seconds >= nmin_empty_release_seconds
- Codice: max_pressure.py:469-475

APPENDICE: FORMULE CHIAVE (RIASSUNTO RAPIDO)
--------------------------------------------

A) Base movement pressure:
   p_m = q_in - q_out

B) Downstream-penalized movement pressure:
   p_m = q_in - q_out - beta * occ_down_ema

C) Phase pressure:
   P_phi = sum_{m in phi}(p_m)

D) Fairness bonus:
   bonus_phi = mu * (w_phi / (w_phi + w_half))

E) Phase score:
   score_phi = P_phi + bonus_phi

F) Lost-time-aware switch margin:
   margin = switch_epsilon + lost_time_gain * sat_flow * T_lost

G) Switch condition:
   switch if score_best > score_current + margin

H) Nmin dynamic target:
   n_cost   = nmin_alpha * sat_flow * T_lost
   n_target = max(nmin_floor, n_cost)
   hold_sec = max(min_green, n_target / sat_flow)

I) EMA occupancy:
   occ_ema(t) = alpha * occ_raw(t) + (1-alpha) * occ_ema(t-1)

J) Spillback hard hysteresis:
   if not blocked:
      blocked = (occ_ema >= on) and (halts >= min_halts)
   else:
      blocked = (occ_ema >= off)
